2. DATASET / MODEL QUICK FACTS
────────────────────────────────────────────────────────────────────────────────

Source        : PRO-ACT clinical database
Train set     : 1,201 samples × 23 features (Short=139, Standard=1,062)
Test set      :   301 samples × 23 features (Short=35,  Standard=266)
Prevalence    : ~11.6% Short Survivors
CV protocol   : RepeatedStratifiedKFold(n_splits=5, n_repeats=3, random_state=42)
Optimiser     : Optuna TPE, 50 trials, metric=AUC
Classifiers   : KNN, NaiveBayes, DecisionTree, RandomForest, SVM, MLP, LightGBM
Strategies    : 10 imbalance techniques (None, ROS, SMOTE, BorderlineSMOTE,
                ADASYN, RUS, NearMiss, TomekLinks, SMOTETomek, SMOTEENN)
                → 70 combinations total

MLP best config:
  tanh, adam, alpha=0.0608, adaptive lr, hidden_layer_sizes=(172,),
  max_iter=1000, no resampling, CV AUC=0.9151, Test AUC=0.9176
  Test: TP=1, FP=0, FN=34, TN=266 (sensitivity=0.029, specificity=1.000)

LightGBM best config:
  ROS, CV AUC=0.9137, Test AUC=0.9228
  Test: TP=30, FP=45, FN=5, TN=221 (sensitivity=0.857, specificity=0.831)

5. POINT 2 — BOOTSTRAP CONFIDENCE INTERVALS (✅ COMPLETE)
────────────────────────────────────────────────────────────────────────────────

What was done:
  A. step12_bootstrap_ci.py created:
       - Reads step6_test_probabilities.json directly (no re-run of models)
       - 2000 bootstrap resamples, percentile interval, random_state=42
       - 5 metrics: AUC, Sensitivity, Specificity, Balanced Accuracy, G-Mean
       - Exclusion rule: samples with 0 Short Survivors → excluded from
         Sensitivity/GMean CIs; count reported
       - Outputs: step12_bootstrap_ci.csv, step12_bootstrap_ci_wide.csv
       - Runtime: ~97s

  B. main.tex updated:
       §3 Evaluation Metrics → paragraph about bootstrap CI methodology
       Table tab:test        → caption updated to point to tab:test_ci
       NEW Table tab:test_ci → companion table with [lo, hi] per metric
       §4.2 paragraph        → updated to reference CIs and note LightGBM/SVM overlap

    AUC difference is also not significant.

    all other classifiers.
